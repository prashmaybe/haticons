Getting Started in 2 Minutes

Include the stylesheet and drop semantic icon elements right into your HTML, Vue, React, or Angular templates.

1

Install or CDN

Add Haticons to your project with npm or load directly via CDN link:

<!-- via CDN -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/
  haticons@1.0.1/dist/css/
  haticons.min.css">
2

Insert Any Icon

Use the standard <i> element with any hi-[name] class:

<!-- Example usage -->
<i class="hi-search"></i>
<i class="hi-heart text-danger"></i>
<i class="hi-cart text-primary"></i>
3

Scale & Colorize

Inherits CSS font-size and color seamlessly with built-in utility multipliers:

<!-- Sizing classes -->
<i class="hi-haticons hi-lg"></i>
<i class="hi-haticons hi-2x"></i>
<i class="hi-refresh hi-spin"></i>
