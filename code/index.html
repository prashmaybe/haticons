Setup Guide • FontAwesome Alternative

Set Up Haticons in Seconds

Choose the workflow that fits your project. Embed with a single line of CDN code, install via your package manager, or use offline vector assets in Figma.

npm

Install in any Node, Webpack, or Vite project:

npm install haticons
Includes TypeScript index.d.ts declarations out of the box.

Yarn

Add as project dependency using Yarn:

yarn add haticons
Fast, reproducible dependencies with package lock support.

pnpm

Disk-space efficient symlinked install:

pnpm add haticons
Saves gigabytes of node_modules disk space across monorepos.

Bundler & Framework Integration (Vite, Webpack, Next.js):

Import CSS or individual tree-shakeable SVG icons directly in your JavaScript / TypeScript files:

CSS / Webfont Import 
// In your index.js / main.ts entry:
import 'haticons/dist/css/haticons.min.css';
Tree-Shakeable SVG 
// Zero webfont overhead:
import cart from 'haticons/icons/cart';
// cart.svg & cart.path available
1

Add Stylesheet to <head>

Just like a FontAwesome Kit or CDN embed, paste this single line inside your HTML <head> to immediately access all 494 icons:

HTML Head 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/haticons@1.0.1/dist/css/haticons.min.css">
2

Drop Icons into HTML

Place icon tags anywhere in your layout. Supports default, Fill, Outline, and Sharp styles:

HTML Body 
<i class="hi-cart"></i>
<i class="hi-heart-fill text-danger fs-2"></i>
<i class="hi-search-outline text-primary fs-2"></i>
<i class="hi-refresh hi-spin"></i>

React / Next.js

Add to your root pages/_app.js or app/layout.tsx:

import 'haticons/dist/css/haticons.min.css';

export default function App() {
  return <i className="hi-cart" />;
}
SSR & Hydration Safe

Vue 3 / Nuxt / Vite

Include in your main.js or nuxt.config.ts:

import { createApp } from 'vue';
import 'haticons/css';
import App from './App.vue';

createApp(App).mount('#app');
