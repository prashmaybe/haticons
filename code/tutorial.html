1 Installation Options

Haticons can be installed as an npm package in Node, Vite, Webpack, Next.js, or loaded directly via jsDelivr / UNPKG CDN.

A. Via Package Manager

# npm
npm install haticons

# yarn
yarn add haticons

# pnpm
pnpm add haticons

B. Via CDN (Quickest for static sites)

Add the full minified stylesheet to your HTML <head>:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/haticons@1.0.0/dist/css/haticons.min.css">

2 Basic HTML Usage

Use the <i> or <span> tag with the hi-[icon-name] class:

<i class="hi-cart"></i>
<i class="hi-heart text-danger"></i>
<i class="hi-search"></i>

Built-in Size Modifiers

Class Multiplier Live Preview
.hi-lg 1.33x size
.hi-2x 2x size
.hi-3x 3x size
.hi-spin Continuous spin animation

3 Modular Category CSS (Zero Waste)

Unlike traditional heavy icon fonts, Haticons splits all 494 icons into 14 distinct categories. You don't need to load the full 23 KB stylesheet if your project only uses a few icons!

Option 1: Load a standalone category bundle

Includes font definition and all category icons in ~1.5 KB:

<!-- Commerce & Payments only (~1.5 KB) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/haticons@1.0.0/dist/css/categories/commerce.min.css">

Option 2: Core + Category-only files (Recommended)

If you use multiple categories, load core.min.css once, then import category glyphs without duplicate @font-face blocks:

<!-- 1. Core webfont & sizing utilities (< 1 KB) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/haticons@1.0.0/dist/css/core.min.css">

<!-- 2. Category glyphs -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/haticons@1.0.0/dist/css/categories/commerce-only.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/haticons@1.0.0/dist/css/categories/directional-only.min.css">

4 Sass / SCSS Workflow

In projects with a Sass pipeline (Vite, Webpack, Nuxt, Next), import partials directly from haticons/scss:

// Custom font path if needed
$hi-font-path: "~haticons/dist/fonts";
$hi-prefix: "hi-";

// Core font-face and classes
@import "haticons/scss/variables";
@import "haticons/scss/core";

// Only import needed categories
@import "haticons/scss/categories/commerce";
@import "haticons/scss/categories/communication";
@import "haticons/scss/categories/directional";

  <span class="input-group-text"><i class="hi-search"></i></span>
  <input type="text" class="form-control" placeholder="Search...">
</div>

6 JavaScript / TypeScript API

Haticons includes a JS/TS module to query icon metadata, unicode codepoints, and category sets dynamically:

import { icons, categories, getIcon, getByCategory } from 'haticons';

// Lookup specific icon
const cartIcon = getIcon('hi-cart');
console.log(cartIcon.content); // "\f063"

// Get all icons for a category
const directional = getByCategory('directional');
console.log(directional.length); // 16
