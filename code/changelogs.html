v1.0.0
October 27, 2026

Official npm Release, Modular Architecture & boodoo Integration

This major release turns Haticons into a first-class npm package, divides the full icon set into 14 independent categories with partial CSS/SCSS files, removes legacy PHP dependencies, and adopts the modern boodoo CSS framework.

🚀 New Features & Optimizations

  • npm Package Publishing: Published as haticons with TypeScript types (index.d.ts), CJS/ESM modules, and query functions (getIcon, getByCategory).
  • 14 Granular Categories: Grouped into Brands, UI & Interface, Commerce, Directional, Media, Editor, Feedback, Files, Devices, Communication, Users, Navigation, Security, and Time.
  • Partial CSS & Sass Imports: Added standalone category stylesheets (commerce.min.css) and pure glyph files (commerce-only.min.css) alongside core.min.css for zero bundle waste.
  • Multi-Page Documentation & Live Tools: Fully transitioned from PHP to modern static HTML architecture featuring a dedicated Full Icon Reference with 14 category anchors and live search utilities, and In-Depth Tutorials.
  • boodoo Framework Styling: Fully redesigned UI with boodoo design system tokens, sticky glass navbar, responsive cards, modals, and toasts.
  • PebbleBenders Authorship: Established open-source governance and branding under PebbleBenders.
