v1.0.1 Latest Release
October 28, 2026

LESS Support, CLI Tool, Framework Components & Utility Addons

Feature and maintenance release introducing complete LESS preprocessor support, an official command-line interface, React and Vue 3 component packages, bundler auto-import resolvers, style variant addon classes and sizing modifiers, along with build pipeline optimizations and clean compilation output.

🚀 New Features & Addons

  • Full LESS Preprocessor Support: Added complete modular LESS sources under less/ (including variables.less, core.less, 14 category files in less/categories/, and bundle entry haticons.less), with "less" and "./less/*" package exports in package.json.
  • Official CLI Utility: Added the haticons executable (bin/haticons.js / npx haticons) for searching glyphs, querying icon categories, inspecting unicode codepoint metadata, and extracting standalone SVGs directly from the terminal.
  • React & Vue 3 Components: Published first-class component packages for React (haticons/react) and Vue 3 (haticons/vue) with complete TypeScript declarations (.d.ts), ESM, and CommonJS builds.
  • Auto-Import Bundler Resolver: Added haticons/resolver compatible with unplugin-vue-components, Vite, and Webpack for automated on-demand component loading.
  • Style Variant Addon Classes: Added style variant suffixes and helper classes (.hi-*-fill / .hi-fill, .hi-*-outline / .hi-outline, and .hi-*-sharp / .hi-sharp) for rapid solid, outline, and sharp icon variants.
  • Built-in Sizing & Animation Modifiers: Added standardized size multipliers (.hi-xs, .hi-sm, .hi-md, .hi-lg, .hi-xl, .hi-2x, .hi-3x, .hi-4x, .hi-5x), animation helpers (.hi-spin, .hi-pulse), transform utilities (.hi-rotate-*, .hi-flip-*), and fixed-width alignment (.hi-fw).
  • Interactive Documentation & Reference Suite: Added the comprehensive Icon Reference Catalog with live search and SVG export modals, an In-Depth Tutorial Guide, and legal pages (Terms, Privacy, License).
  • Server Caching & Compression: Added Apache .htaccess configuration with Gzip/Brotli compression rules, Webfont CORS headers (Access-Control-Allow-Origin: *), and browser caching directives.

🔧 Fixes & Improvements

  • Dart Sass Compiler Warnings: Added --silence-deprecation=import flags to build pipelines in scripts/compiler.js for clean and silent build execution.
  • Asset CDN URLs: Updated documentation and interactive snippets to reference v1.0.1.

v1.0.0
October 27, 2026

Official npm Release, Modular Architecture & boodoo Integration

This major release turns Haticons into a first-class npm package, divides the full icon set into 14 independent categories with partial CSS/SCSS files, removes legacy PHP dependencies, and adopts the modern boodoo CSS framework.

🚀 New Features & Optimizations

  • npm Package Publishing: Published as haticons with TypeScript types (index.d.ts), CJS/ESM modules, and query functions (getIcon, getByCategory).
  • 14 Granular Categories: Grouped into Brands, UI & Interface, Commerce, Directional, Media, Editor, Feedback, Files, Devices, Communication, Users, Navigation, Security, and Time.
  • Partial CSS & Sass Imports: Added standalone category stylesheets (commerce.min.css) and pure glyph files (commerce-only.min.css) alongside core.min.css for zero bundle waste.
  • Multi-Page Documentation & Live Tools: Fully transitioned from PHP to modern static HTML architecture featuring a dedicated Full Icon Reference with 14 category anchors and live search utilities, and In-Depth Tutorials.
  • boodoo Framework Styling: Fully redesigned UI with boodoo design system tokens, sticky glass navbar, responsive cards, modals, and toasts.
  • PebbleBenders Authorship: Established open-source governance and branding under PebbleBenders.
